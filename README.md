# ITDEV-154: Data Structures and Programming

### Milwaukee Area Technical College

My Java coursework from ITDEV-154 at MATC.

## Activities

**[BinarySearch](BinarySearch/)**

Finds a number in a sorted array.

**[BubbleSort](BubbleSort/)**

Sorts numbers and displays each pass.

**[BracketChecker](BracketChecker/)**

Checks matching brackets using a stack.

**[StringReversal](StringReversal/)**

Reverses text using recursion.

**[PartitionSort](PartitionSort/)**

Partitions an array and sorts it using insertion sort.

**[BinarySearchTree](BinarySearchTree/)**

Finds the smallest and largest values in a binary search tree.

**[NameHashTable](NameHashTable/)**

Stores names in a hash table.

**[GraphMatrix](GraphMatrix/)**

Displays a graph as an adjacency matrix.
